06

Motion & Interaction

  • Conquest — node fills green with a 700ms pop (--ease-pop) + confetti burst; region % ticks up. Reserved for real achievement only.
  • Buttons — hover lifts with the 3px hard shadow; press snaps flat. Feels like pressing a physical sticker.
  • Answer feedback — border + tint transition 200ms; correct gets a check draw-in, wrong a single 4px shake.
  • Streak increment — flame scales 1→1.15→1 with count roll-up; freeze token shows a blue frost sweep.
  • Sheets — topic sheet slides up 350ms; rank-up is the only full-screen takeover.
  • Decay — no animation; territories dim quietly. Urgency lives in the revision stack count.
