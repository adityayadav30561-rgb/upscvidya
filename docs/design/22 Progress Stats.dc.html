Interaction notes

  • Calendar cells encode goal completion, not mere opens — green solid = daily pace met, tint = partial, dashed red = missed (freeze token days show the blue frost tint). Tap a day → that day's activity timeline.
  • Weekly bars: green = goal met, sand = under, orange = today (live). Long-press a bar for the split (reading vs quiz vs revision).
  • Accuracy line plots weekly average against the 70% conquest line; crossing it fires a one-time "consistently conquest-grade" commendation.
  • Study minutes count active engagement only (scroll/answer events), not screen-on time — stated honestly in a footnote sheet.
  • Today's activity is the same data the Home mission card reads — the "due" row deep-links to the briefing.
  • Range picker (This week ▾) swaps all three charts together: week / month / campaign-to-date.
  • Desktop: calendar left, charts stacked right in a 2-col band; timeline full-width below.
