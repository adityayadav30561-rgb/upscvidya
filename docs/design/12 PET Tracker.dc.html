Interaction notes

  • Trend charts plot logs against the dashed qualifying line — crossing it flips the event chip to QUALIFYING with a green pop.
  • PET READY badge: dashed khaki while pending → solid gold with glow when all 4 hold on 3 consecutive logs; it then appears on Profile and Leaderboard.
  • Log sheet: time input is a large stepper/dial (thumb-friendly outdoors); delta line computes live against last log and the standard.
  • Standards switch (male/female) lives in settings and relabels every chart line; values follow the official CAPF PET table.
  • A regression (3 slower logs in a row) shows a gentle "fatigue? schedule a rest day" note — never red alarm.
  • Reminder cadence configurable: default 3×/week nudge, silent on rest days.
  • Desktop: four event cards in a 2×2 grid, each with its full trend chart; log entry as a right panel.
