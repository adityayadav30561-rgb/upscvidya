Interaction notes

  • Map scrolls vertically through regions in syllabus order; region chips row is horizontally scrollable and taps jump-scroll.
  • Guided road: solid orange segment = next leg; dashed orange = planned route; khaki dots = travelled. Segment draws in (700ms) after each conquest.
  • Node tap → topic sheet slides up 350ms with scrim; sheet CTA reflects state (unconquered → "Attempt quiz", conquered → "Retake for gold", decaying → "Reinforce now").
  • Conquest: node pops green (--ease-pop), road segment draws to the next node, region % ticks up.
  • Decaying nodes (DPSP) dim + dashed, show days stale; no alarm animation — urgency lives in the Revision Stack.
  • Secured regions collapse to a banner row (Foundations) to keep the map short; tap expands.
  • Desktop: regions flow in a 2-col masonry; topic sheet docks as a right panel instead of a bottom sheet.
